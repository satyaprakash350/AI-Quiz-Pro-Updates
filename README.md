AI Quiz Pro

AI Quiz Pro is an Android application for generating interactive quizzes on different topics using AI.

Purpose of This Repository

This repository is used to publish development updates, APK downloads, and release notes for AI Quiz Pro.

Downloads

Visit the "Releases" (../../releases) section to find available APK downloads and their corresponding release notes.

Development Status

AI Quiz Pro is currently under development. Features and functionality may change between releases.

Installation

Download an APK from the Releases section and install it on a compatible Android device.

Android may ask you to allow installation from the application used to download the APK. Only install APKs from sources you trust.

Updates

Release notes describe the changes, improvements, and bug fixes included in each version.
